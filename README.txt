DESKRIPSI APLIKASI
Aplikasi ini merupakan sistem pakar sederhana untuk
mengidentifikasi kemungkinan penyakit umum berdasarkan
gejala yang dipilih oleh pengguna.

Aplikasi dibuat menggunakan Python dan Streamlit
dengan metode Forward Chaining.

CARA MENJALANKAN APLIKASI

1. Pastikan Python sudah terinstal.
2. Buka terminal pada folder aplikasi.
3. Instal library dengan perintah:
   pip install -r requirements.txt
4. Jalankan aplikasi dengan perintah:
   streamlit run app.py
5. Buka alamat localhost yang muncul pada terminal.

CATATAN
Aplikasi ini dibuat untuk keperluan pembelajaran.
Hasil identifikasi bukan diagnosis medis.
